# دفتر ثبت سؤال‌ها و الزامات — کندوی کابینی سیار

## قواعد این دفتر

- هر سؤال یک شناسه‌ی ثابت دارد (`Q-01`، `Q-02`، ...). شناسه‌ها **هرگز** تغییر نمی‌کنند و دوباره استفاده نمی‌شوند.
- اگر جواب یک سؤال عوض شود، **همان ردیف** به‌روز می‌شود و تغییر در «تاریخچه‌ی تغییرات» پایین صفحه ثبت می‌شود. برای یک سؤال هیچ‌وقت دو جواب هم‌زمان وجود ندارد.
- الزاماتی که خارج از سؤال‌ها مطرح می‌شوند، شناسه‌ی `R-xx` می‌گیرند.
- وضعیت هر ردیف: **قطعی** / **نیاز به شفاف‌سازی** / **باز** (بی‌جواب).
